# قانون‌یار معاملات

پایگاه جست‌وجوی آفلاین فارسی برای موضوعات مناقصه و مزایده. نسخه عمومی و خصوصی دو SQLite جدا هستند.

## اجرا

نیازمندی: Python 3.10 یا جدیدتر؛ وابستگی بیرونی ندارد.

در PowerShell از پوشه‌ای که این فایل در آن است:

```powershell
python app.py
```

برای پایگاه خصوصی شرکت:

```powershell
python app.py --private
```

سپس نشانی چاپ‌شده در مرورگر باز می‌شود. سرویس فقط روی همین رایانه (127.0.0.1) گوش می‌دهد. فایل خصوصی و PDFهای شرکت را در مخزن/نسخه عمومی قرار ندهید.

## محتوا و پوشش فعلی

- ۲۹۲ سرفصل و شماره صفحه از تصاویر فهرست چاپی شماره ۲۷، بهار ۱۴۰۳؛ تطبیق این فهرست با ویرایش دوازدهم هنوز قطعی نشده است.
- نسخه عمومی: ۳۰ یادداشت ماده‌محور از قانون برگزاری مناقصات و یک منبع نصاب سالانه ۱۴۰۵.
- نسخه خصوصی: علاوه بر محتوای عمومی، ۲۹ ماده اساسنامه شرکت که از اسکن ۸ صفحه‌ای بازخوانی شد؛ ۵۶ ماده از آیین‌نامه قدیمی؛ مواد قابل استخراج (۲۴ ماده) از نسخه موسوم به ویرایش آخر؛ و متن صفحه‌ای هر سه PDF.
- هر دو آیین‌نامه شرکت تاریخ تصویب خالی دارند؛ تصویب/ابلاغ و لازم‌الاجرا بودن آنها از فایل‌ها احراز نشده است. نسخه جدید فقط به‌عنوان پیش‌نویس/متن دریافتی قابل جست‌وجو است.
- ۲۲۴ سرفصل هنوز پژوهش نشده‌اند؛ ۶۸ سرفصل در جریان‌اند. این پایگاه فعلاً پژوهش عمیق تک‌تک سرفصل‌ها را کامل نمی‌کند.
- متن کامل کتاب قانون‌نامه در پایگاه نیست. تنها فراداده سرفصل‌ها و منابع حقوقی مستقلاً بررسی‌شده درج شده‌اند.

گزارش تفصیلی را از پیوند «دریافت گزارش پوشش» در برنامه بگیرید یا فایل `outputs/coverage_report.md` را ببینید.
